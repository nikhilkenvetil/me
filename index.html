Real-Time Cab Data Analytics Pipeline

Built an end-to-end data engineering pipeline using Azure, Spark, PostgreSQL, and Grafana. Automated data ingestion, sanitization, and visualization via Apache Airflow and Docker.

  • Data Ingestion: Data required for this workflow was being ingested from an Azure Storage, specifically created for this use case. The specific storage account was populated with the required data in a timely manner - 100 records every 2 minutes - to simulate a real-time scenario on an off-peak hour. This was accomplished by using REST API calls to GET data from BigQuery dataset, and the response was written into a JSON file and saved into the Azure Storage blob account.
  • Data Sanitization: The data received was sanitized by employing a Spark cluster, where any rows with NAs was simply dropped. Since this was just a prototype, this was permitted.
  • Data Storage: The sanitized data was then pushed into a PostgreSQL database.
  • Data Analysis and Visualization: The data was then analysed and visualized using Grafana.
  • This whole setup was orchestrated using Apache Airflow. Every component in this project was Dockerized.
